# FashionWorld 🛍️

**The world's first immersive 3D virtual fashion mall for Spanish-speaking consumers.**

Walk through a real 3D mall. Enter branded stores. Try clothes on an AI-powered avatar with your exact body measurements. Share your outfit with a friend via WhatsApp and shop together — virtually.

## Live Demo
Open `public/index.html` in Chrome.

## Features
- 🏬 5 branded stores — ICONY + 4 partner brands (prototype placeholders)
- 🚶 **3D immersive mall** — WASD navigation, mouse look, proximity detection
- 👗 **Body scan onboarding** — 3 methods: photo scan, manual measurements, quick setup
- 🪞 **AI fitting room** — Claude Vision analyzes your photo and shows how garments look on YOU
- 👯 **Social shopping** — "Ask a Friend" WhatsApp share link
- 🎨 **Mood board** — editorial looks and trend filters
- ✨ **Mall atmosphere** — NPCs, fountain, plants, hanging lights, particles

## Tech Stack
- Three.js r128 (3D mall)
- HTML5 Canvas (avatar rendering)
- Anthropic Claude API (AI try-on)
- Vanilla JS — no framework, no build step
- Single HTML file — runs anywhere
